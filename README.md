# PowerPoint Dojo

S'entraîner sur PowerPoint, de débutant à champion du monde, **dans ta vraie présentation** (Mac, Windows, web).
Add-in Office.js + site statique. Voir `CLAUDE.md` pour l'architecture et le plan.

- Installer : page `/install` du site (génère `manifest.xml`).
- Mode fichier : ouvrir le site dans un navigateur, télécharger l'exercice en .pptx, le faire, le redéposer.
- Dev : `npm install`, `npm run verify`, `npm run build`, `DOJO_HTTP=1 npm run dev`.
